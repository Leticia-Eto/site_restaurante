# Site Restaurante

Bem-vindo ao repositório do **Site Restaurante**! Este projeto foi desenvolvido durante meus primeiros passos como desenvolvedor, por isso a estrutura do código é mais simples e sem funcionalidades avançadas como JavaScript. A ideia do site é oferecer uma experiência básica para um restaurante, com foco no design e na interação com os serviços de forma simples e intuitiva.

## 🛠 Tecnologias Utilizadas

As ferramentas utilizadas para a contrução do projeto foram:

- Html
- CSS
- IDE: Visual Studio
